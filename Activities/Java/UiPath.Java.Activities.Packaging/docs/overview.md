# UiPath Java Activities

`UiPath.Java.Activities`

Reference documentation for Java XAML activities in the Java package.

## Activities

### Java

| Activity | Description |
|----------|-------------|
| [Convert Java Object](activities/ConvertJavaObject.md) | Converts a Java object handle to a typed .NET value. |
| [Create Java Object](activities/CreateJavaObject.md) | Creates a Java class instance using a constructor and optional parameters. |
| [Get Java Field](activities/GetJavaField.md) | Reads an instance or static field from a Java class. |
| [Invoke Java Method](activities/InvokeJavaMethod.md) | Invokes an instance or static Java method with optional parameters. |
| [Java Scope](activities/JavaScope.md) | Starts a Java bridge session and hosts Java child activities. |
| [Load Jar](activities/LoadJar.md) | Loads a JAR file into the active Java scope runtime. |

## Platform

All activities in this package are cross-platform.
